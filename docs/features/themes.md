# Themes

Two, plus "follow the device": **Light**, **Dark**, **Device**, under
**Settings → Appearance**. The default follows the device.

The framework the app is built on ships a dozen palettes and a full
appearance picker; this app deliberately exposes none of them. A recorder is
looked at while something else is happening — a meeting, a thought, a
rehearsal — and earns nothing from a theme gallery; what it needs is a meter
that reads at a glance in either theme, and a red that means one thing.
