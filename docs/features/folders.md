# Folders

**Folders** is the tree: a folder can hold folders, each shows how many
recordings are inside it, and the order is yours — move a folder up or down,
or into another one. **New folder** makes one at the top level or inside the
folder you are on.

A folder is a label, not a container: deleting one moves the recordings and
the folders inside it up a level and deletes nothing recorded. A recording is
filed into a folder from the naming sheet when it is saved, or from its menu
in the list afterwards.

Folders belong to a space (see [`spaces.md`](spaces.md)): each space has its
own tree, synced with its own index.
