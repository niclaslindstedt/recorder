# Folders

A folder is a label on a recording, so folders are filed, switched and
arranged where the recordings are — there is no folders page. It is all one
**folder picker**, which opens in two forms:

- **Browsing**, from the scope at the top of **Recordings**: **All
  recordings**, **Favorites**, the tree (a folder can hold folders, and each
  shows how many recordings are inside it), **New folder** and **Recently
  deleted**. Pick one and the list shows it.
- **Choosing**, from **Move to folder** (a row's menu, or the folder chip in
  the player) and from **Save to** on the Record screen: **No folder**, the
  tree, and **New folder**. The current choice is ticked.

**New folder** is always the last item in the tree. It asks for a name and
where it goes — the top level, or inside a folder, starting on the one that
is selected. Made while choosing, the new folder is then chosen, so moving a
recording to a folder that does not exist yet is one step, not a detour.

While browsing, each folder has a **⋯** menu for the tree itself: **Rename
folder**, a **new folder inside** it, **Move folder** (to the top level or
into another folder, never into itself), **Move up** and **Move down** — the
order is yours — and **Delete folder**.

A folder is a label, not a container: deleting one moves the recordings and
the folders inside it up a level and deletes nothing recorded.

Folders belong to a space (see [`spaces.md`](spaces.md)): each space has its
own tree, synced with its own index.
